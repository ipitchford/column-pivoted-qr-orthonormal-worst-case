Release replay environment (16 November 2026, macOS arm64 host)
Interpreter: CPython 3.12.11 (uv-managed; checked inside the run with sys.version; invoked as `python`, because a
`python3` shim on the host can resolve to another version)
Packages: numpy 2.3.5, scipy 1.17.0, sympy 1.14.0, mpmath 1.3.0, matplotlib 3.10.8 (requirements.txt)
NumPy longdouble on this host: float64 (on x86-64 Linux it is 80-bit extended precision).
GitHub CI: ubuntu-latest, actions/setup-python 3.12, pip-installed pins as above.
Cross-platform comparison (declared before tagging; same policy in CI, README.md and REPLAY_RECEIPT.md):
- results/fingerprints.json must be byte-identical, and results/extensions.json identical apart from its "python" field,
  which records the interpreter version (exact rational and 50-digit mpmath arithmetic; these files contain no
  floating-point numbers). results/initial-failed-run.json is a fixed record of the initial run and is not regenerated.
- results/verification.json is compared field by field: structure, booleans, integers and non-numeric strings
  (including exact rationals) exactly; JSON numbers within relative 1e-9 with absolute floor 1e-12; decimal numeric
  strings within relative 1e-12; every relative_disagreement field below 2e-14 in both files (the script's own
  criterion); the finite-difference rounding diagnostics frobenius_error, trace_derivative and
  derivative_frobenius_error below 2e-8 in absolute value in both files (the script's own threshold), not compared
  with each other because they measure rounding noise (for example 1.3e-11 on macOS and 2.3e-11 on Linux CI); the fields run_utc, elapsed_seconds, versions, vector_arithmetic, root_solver_evaluations and
  root_solver_message are ignored. Reason: the large-rank core sums use NumPy longdouble, whose width depends on the
  platform, and the root solver may take a different number of evaluations (32 or 36 have been seen); last-digit
  differences of about 1e-15 relative are expected.
- figures/sharp-growth.png and .pdf are regenerated in a non-blocking job and not compared (font rendering differs
  across platforms; the PDF also carries a creation date).
